# Little Knight [![build](https://github.com/pathikrit/little-knight/actions/workflows/pages.yml/badge.svg)](https://github.com/pathikrit/little-knight/actions/workflows/pages.yml)

Little app for beginner chess.

```sh
npm ci        # install dependencies
npm run dev   # run locally in watch mode
npm run site  # used in CI to make static page
npm test      # run tests
```
